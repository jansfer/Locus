# Locus v0.19.76 更新

## 修复

- **ChatGPT 订阅登录回调「localhost 拒绝连接」** — 授权完成后浏览器跳转 `http://localhost:1455` 提示无法访问，登录流程卡住。原因有二：回调服务器只绑定 IPv4 的 `127.0.0.1`，而 `localhost` 在部分环境优先解析为 `::1`；以及端口绑定失败（被占用或被 Windows 动态保留范围覆盖）时错误被静默吞掉，服务器根本没启动。现在：
  - 登录发起前预检端口，优先双栈绑定，`localhost` 无论解析成 IPv4 还是 IPv6 都可达；
  - 端口被其他程序占用时明确提示关闭占用程序（常见于上次登录未结束或 Codex CLI 正在运行）；
  - 端口被 Hyper-V / WSL 动态保留时给出对应处理指引（`net stop winnat` + `net start winnat` 或重启电脑）；
  - 登录界面新增回调地址粘贴入口：浏览器授权后即使提示无法访问 localhost，把地址栏完整 URL 粘贴进 Locus 点「完成登录」即可拿到凭据——token 交换不依赖本地端口；
  - 授权页链接在自动打开失败时也可手动点击；
  - 已配置代理时会提示把 `localhost` 加入直连列表。

## 说明

- macOS 安装包若未配置签名证书，首次打开仍需在「系统设置 → 隐私与安全性」中手动放行。
