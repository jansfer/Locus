# Locus v0.19.89

## Fixes

- Upgrade the bundled Pi runtime from 1.4.0 to 1.6.1, which brings GPT-6.2 Astra and Sol, GPT-6.1 Terra, faster streaming of large tool calls, and a longer list of transient provider failures that are retried automatically instead of failing the turn.
- Keep Locus' native retry patch on the new runtime. Transient stream read failures, gateway bodies that end mid-response, and browser-side `Failed to fetch` errors still retry inside the same transcript, so completed tool results are not replayed.
- Adapt the Antigravity adapter to the runtime's changed Google shared API. Tool strict-mode detection now receives the model instead of its ID, and the finish reason mapping moved back into the adapter, keeping `STOP` as a normal end, `MAX_TOKENS` as a length stop, and every other upstream value as an error.
- Add regression tests for the Antigravity finish reason mapping, covering a normal end, a length stop, an upstream error value, a tool-call turn, and a stream that ends without any finish reason.
