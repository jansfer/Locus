# Locus v0.19.79 Update

## Documentation

- The default `README.md` is now written in English, following the common convention for open-source projects on GitHub; the Chinese version moved to `README.zh-CN.md`, and both files link to each other at the top.
- Project development guidelines now require AI-generated git commit messages, PR descriptions, and release notes to be written in English, keeping the repository readable for international contributors. Code comments, console logs, and in-app Chinese engineering docs remain Chinese by design.

## Internationalization

- Continued polish of the Simplified Chinese / English bilingual interface introduced in v0.19.78 (no behavior changes in this release).
