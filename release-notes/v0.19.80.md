# Locus v0.19.80 Update

## Fixed

- Channel-type labels in the "Add channel" flow (type dropdown, channel list, and auto-generated channel names) were still rendered in Chinese regardless of the interface language. They now follow the active language from the i18n dictionaries, e.g. "Qwen (Tongyi)", "Volcano Engine (Doubao) API", "OpenAI Chat Completions (custom URL)". Existing channels whose names were auto-filled from the old Chinese labels keep working; switching providers in the form now updates the default name in the active language.
