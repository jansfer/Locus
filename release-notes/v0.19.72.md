# Locus v0.19.72 更新

## 新功能

- **定时任务启动补跑** — 应用退出期间到期的定时任务，会在下次启动后自动补跑一次，不再被静默跳过。每个任务只补最近错过的一轮，不会把关闭多天期间的所有周期全部重放；多个补跑任务严格串行执行，上一个任务结束后才开始下一个，避免启动时同时拉起多路 Agent 抢占资源。
- **补跑遵守执行窗口** — `interval` 任务仅在当前仍处于每日执行窗口与运行日允许的时段内补跑。例如配置 10:00–22:00 的任务在 23:00 启动，只会把下次触发顺延到次日窗口，不会在窗口外执行。`daily` / `weekly` / `monthly` / `once` 过期即补跑。
- **补跑可追溯** — 补跑产生的运行记录在任务详情的「运行历史」中显示「补跑」标记，飞书通知也会注明「启动补跑（应用未运行期间错过的任务）」。
- **项目搜索按需展开** — 左侧栏「项目」区块的常驻搜索框改为搜索按钮，默认不再占用列表空间。点击后展开并自动聚焦；再次点击或按 `Esc` 收起，收起时清空查询，避免列表保留看不见的过滤条件。

## 说明

- 补跑队列在应用启动约 5 秒后开始，任务之间间隔 3 秒；单个任务仍受 2 小时执行超时保护。
- 补跑前会重新读取任务状态，已暂停、已删除或缺少模型/项目配置的任务会直接跳过。
- macOS 安装包若未配置签名证书，首次打开仍需在「系统设置 → 隐私与安全性」中手动放行。
