# Locus v0.19.83

## Features

- Add an Antigravity (Google subscription) model channel with browser OAuth login and manual callback fallback.
- Add grouped quota queries and enable the existing quota display for this provider. Missing quota data and failed requests are shown as unknown rather than exhausted quota.

## Fixes

- Fix Antigravity chat startup failing with “An object could not be cloned.” Refresh callbacks now stay in the main process and use capability RPC across the Agent runtime boundary.
- Unwrap the Antigravity model catalog and SSE response envelopes so model discovery, responses, and tool calls can be consumed correctly.
- Use the configured proxy throughout login, preserve cancellation during credential exchange, and enforce per-request timeouts.
- Register callback handlers before opening the browser and keep unrelated requests from consuming the handler.
- Load Pi's ESM-only modules dynamically to prevent application startup failures in Electron's CommonJS main process.
