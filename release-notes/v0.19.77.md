# Locus v0.19.77 更新

## 修复

- 修复 v0.19.76 在本地 1455 端口不可用时提前终止 ChatGPT 订阅登录、导致点击登录后浏览器不打开的问题。端口被占用或绑定被拒绝时，现在仍会继续浏览器授权，并提供手动回调输入路径。
- 浏览器授权后若提示 localhost 无法访问，将地址栏的完整回调地址粘贴到 Locus，点击「完成登录」即可继续；也可选择设备码登录。
- 修正登录预检或代理读取失败后的状态清理，并保留原有回调主机环境配置。
- 不再仅凭 EACCES 错误断定 Windows 动态端口保留，避免给出不准确的系统服务操作指引。
