# Locus v0.19.75 更新

## 新功能

- **新增热门模型支持** — 更新 GPT-6.1 Terra / GPT-6.1 Sol、Gemini 4 Argon、Kimi K3.1 Pro 等近期发布模型的识别与接入，模型选择器、上下文窗口与推理档位均已对齐官方规格。
- **GPT-6.1 系列完整接入** — ChatGPT (Codex) 渠道新增 GPT-6.1 Terra 与 GPT-6.1 Sol（500K 上下文、128K 输出），并支持 Codex Fast Mode 优先通道；GPT-6.1 不再支持关闭思考，推理档位默认 high，选择 off 时自动归一化为 low。
- **Kimi K3.1 Pro 预设** — Kimi API 与 Kimi Coding Plan 渠道预设加入 Kimi K3.1 Pro（1M 上下文）；存量渠道会在下次启动时自动补入该候选模型，不影响已启用的旧模型。
- **Gemini 4 Argon 能力表** — 1M 上下文、32K 最大输出，思考档位 low / medium / high，默认 high；非法档位自动归一化。

## 改进

- GPT-6 / GPT-6.1 全系列使用专属图标，不再回落到 GPT-5 图标。
- 模型下线引导（v0.19.74 引入）在推荐替代模型时能正确识别上述新模型的家族与版本，避免把新模型误判为旧模型的降级。

## 说明

- 首代 GPT-6 Astra / Sol / Luna 的上下文窗口与推理档位保持不变。
- macOS 安装包若未配置签名证书，首次打开仍需在「系统设置 → 隐私与安全性」中手动放行。
