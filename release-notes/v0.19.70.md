# Locus v0.19.70 更新

## 新功能

- **六平台原生安装包** — Windows、macOS、Linux 各提供 amd64 与 arm64 两个架构，共六个目标。全部在相同平台与架构的 Runner 上原生构建，不再依赖 x64 仿真或交叉编译；CLI、OfficeCLI、Electron 与原生模块严格匹配目标架构，Windows ARM64 与 Linux ARM64 的产物因此可以真实运行。
- **安装包命名规范化** — 统一为 `Locus-版本-系统-CPU.扩展名`。`amd64` 表示 Intel / AMD 64 位处理器，`arm64` 表示 ARM 64 位处理器（包含 Apple Silicon）。Linux deb 包此前使用 `locus_版本_架构.deb` 的另一套命名，现与其余平台对齐。
- **已归档项目独立分组** — 项目列表新增归档切换按钮，仅在存在归档项目时出现。归档项目在列表底部以「已归档项目」单独成组展示，可一键收起或展开；归档后自动贴近收起状态，搜索时归档区显示「已归档项目：未找到匹配的项目」。

## 修复

- **Linux ARM64 deb 打包失败** — electron-builder 打包 deb 时会自行下载 x86 版的 FPM 工具，在 ARM64 构建机上是无法执行的二进制。现在构建前安装原生 Ruby 与 FPM 1.17.0，并通过 `USE_SYSTEM_FPM` 强制使用系统工具，两种 Linux 架构统一使用这一固定版本。
- **归档项目误触发拖拽排序** — 已归档项目此前仍响应拖拽事件，可能被拖动或当作投放目标，导致排序状态错乱。现在归档分组内不再绑定拖放监听，投放目标命中归档项目时直接忽略。

## 自动更新兼容

安装包改名对已有用户无影响，更新清单继续沿用 electron-updater 的既有名称：Windows 为 `latest.yml`，macOS 为 `latest-mac.yml`，Linux 分别为 `latest-linux.yml` 与 `latest-linux-arm64.yml`。

Windows 清单固定把 amd64 安装包放在第一项，以兼容旧版 x64 更新器的回退选择；ARM64 客户端按文件名中的 `arm64` 选中正确工件。macOS 清单同时提供两个架构的 ZIP 与各自校验值。旧版本的差量更新可能因命名变化找不到历史 `.blockmap`，此时 electron-updater 会自动回退为完整下载。
