# Locus v0.19.87

## Features

- Curate the Antigravity model catalog to current, chat-capable models. Internal automation entries (`chat_*`, `tab_*`), retired generations (Gemini 2.5, older Flash tiers) and non-chat modalities are filtered out, fixed-tier aliases collapse into the bare model when both exist, results are ordered by recommendation and version, and the selection falls back to all non-noise entries if version baselines would empty the list.
- Add reasoning-level control for Antigravity models. Bare Gemini 3+ models expose low/medium/high through `thinkingLevel`, Claude models expose budget-based levels, and fixed-tier variants (`-high`/`-medium`/`-low`) report no control because their depth is encoded in the model ID.

## Fixes

- Make Antigravity subscription quota queries survive a single rejection. The request now sends `cloudaicompanionProject` first with an empty-body retry, treats 403 as retryable across the daily/sandbox/prod endpoints, and reports whether a 403 means Google account verification is required or the subscription is restricted. Missing project IDs are resolved and persisted during credential resolution.
- Show locally declared GPT-6.1 models in the ChatGPT (Codex) channel. GPT-6.1 Terra and Sol were resolvable at request time but missing from the model list because it skipped the local model patch layer; existing channels also receive them as candidates without a manual model re-fetch.
- Remove stored internal Antigravity model entries once at configuration load, without touching manually added models or emptying a channel.
