# Locus v0.19.78 更新

## 新功能

- 应用界面支持简体中文与 English 双语。默认跟随系统语言（中文系统用简体中文，其他用英文），可在「设置 → 通用设置 → 语言」中手动切换；切换后所有窗口、菜单、托盘和通知即时更新，无须重启，选择会持久保存。
- Agent 默认回复语言随界面语言变化：新会话与恢复的旧会话都从下一次发送开始采用当前语言；正在执行的任务保持原语言。消息中明确指定的语言与项目指令优先于默认设置；定时任务与协作子会话同样按当前界面语言生效。
- 日期、时间与数字按当前语言格式化显示（基于 Intl，无新增运行时依赖）。

## 改进

- 设置文件改用原子写入（临时文件 + 重命名 + 备份），降低崩溃或断电导致的配置损坏风险。
