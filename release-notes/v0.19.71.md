# Locus v0.19.71 更新

## 发布流程

- **Release 说明改为优先使用仓库内文件** — 此前发布说明完全依赖 GitHub 按合并的 Pull Request 自动归纳；直接推送到 `main` 的提交没有 PR 元数据，生成的正文只剩一行 compare 链接。现在发布流程会先检查 `release-notes/v<版本>.md`，存在时直接以其正文发布，缺失时才回退到自动生成，仓库内说明文件存在但为空会阻止发布。
- **v0.19.70 的说明已补齐** — 六平台原生打包、工件命名规范化、Linux ARM64 deb 修复与归档项目拖拽隔离的完整说明已写入该版本的 Release 页面。

## 说明

本版仅调整发布流程，应用功能与 v0.19.70 一致。若你已安装 0.19.70，无需为功能更新而升级；想留在同一功能版本可跳过本次更新。
