# Locus v0.19.90

## Fixes

- Recognize the GPT-6.2 Astra and Sol models across the app. Model family detection, context window inference, reasoning profiles, and Codex Fast Mode support now all accept `gpt-6.2-astra` and `gpt-6.2-sol`, instead of treating them as unknown models with a 200K window.
- Use per-model context windows for GPT-6.2: Astra is 272K and Sol is 500K. The previous generation-based rule assumed one window per generation, which no longer holds.
- Complete dated GPT-6.2 Astra model IDs with the correct baseline. Unknown SKUs such as `gpt-6.2-astra-20261001` now inherit the 272K window and the GPT-6.2 Astra metadata rather than the first-generation 372K baseline.
- Add GPT-6.2 Astra and Sol as preset candidates for existing ChatGPT (Codex) channels, so upgrading does not require manually refreshing the model list. User-renamed or disabled entries are left untouched, and the migration runs only once.
